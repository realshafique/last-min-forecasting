## 🚀 Overview

**Last Min Forecasting** is an end-to-end AI-powered web application that predicts the next hour's electricity consumption using a Long Short-Term Memory (LSTM) neural network.

The application takes the previous **24 hours of electricity consumption data** as input and generates a forecast for the next hour.

The project combines:

- Deep Learning
- Time-Series Forecasting
- FastAPI
- React
- REST APIs
- Data Visualization
- Cloud Deployment
